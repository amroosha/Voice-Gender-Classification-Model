# Local Model Artifacts

This directory stores all model artifacts used for training and offline serving.

## Directory Layout

```
models/
├── wav2vec2-base/               # Offline feature extraction backbone
│   ├── model.safetensors        # Pretrained Wav2Vec 2.0 neural network weights (~360MB)
│   ├── config.json              # Model architecture config (12 layers, 768-dim)
│   ├── preprocessor_config.json # Audio preprocessor config (16kHz, normalize=True)
│   ├── processor_config.json    # Combined processor config
│   ├── tokenizer_config.json    # Tokenizer settings
│   └── vocab.json               # Vocabulary mapping
│
├── gender_classifier.joblib     # Exported downstream classifier pipeline
└── gender_classifier.json       # Metadata containing class label mappings
```

## How Models Are Loaded

- **Wav2Vec2 Backbone (`models/wav2vec2-base/`)**:
  - Automatically detected by `src/config.py` via `WAV2VEC2_LOCAL_DIR`.
  - Loaded with `local_files_only=True` in `src/feature_extractor.py`.
  - Requires **zero internet connection** at runtime.

- **Downstream Classifier (`models/gender_classifier.joblib`)**:
  - Generated by running `uv run python -m src.train`.
  - Loaded once at startup by `app/main.py` via FastAPI lifespan state.
